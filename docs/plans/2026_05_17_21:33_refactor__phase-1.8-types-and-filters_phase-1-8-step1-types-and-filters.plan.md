# Implementation plan — Phase 1.8 Step 1 (Types and FilterManager)

## Objective
Replace weak structures (tuple/raw specs) with explicit typing and OO filter encapsulation while strictly preserving current file selection/exclusion behavior.

## Planned changes
- Create types module [`/opt/AIContextCraft/craft/types.py`](/opt/AIContextCraft/craft/types.py) with `ProcessedFile(path: str, content: str)`.
- Refactor [`/opt/AIContextCraft/craft/filter_manager.py`](/opt/AIContextCraft/craft/filter_manager.py) to keep `normalize_glob_patterns` and add `FilterManager(config: dict, output_path: Path)` that:
  - normalizes `include_patterns`, `common_filters`, `project_only_filters`, `tree_only_filters`;
  - adds automatic output file exclusion (`f"{output_path.stem}*"`);
  - builds and stores internal `PathSpec` (include/project/tree);
  - exposes `is_included`, `is_project_excluded`, `is_tree_excluded` (with `is_dir=True` via `/` suffix).
- Update [`/opt/AIContextCraft/craft/tree_generator.py`](/opt/AIContextCraft/craft/tree_generator.py):
  - `generate_tree` and `_collect_tree_paths` receive `FilterManager` instead of raw specs;
  - directory pruning (`os.walk topdown`) uses `is_tree_excluded(..., is_dir=True)` for same non-descent behavior.
- Update [`/opt/AIContextCraft/main.py`](/opt/AIContextCraft/main.py):
  - replace manual spec building with `filter_manager = FilterManager(config, output_path)`;
  - keep existing ignore-files logic (`IgnoreManager`) before filters;
  - replace `files_data.append((relative_path_str, content))` with `ProcessedFile(...)`.
- Update [`/opt/AIContextCraft/craft/formatter.py`](/opt/AIContextCraft/craft/formatter.py):
  - type `files_data` as `list[ProcessedFile]` in `build_output` and helpers;
  - replace tuple access with attributes (`file_data.path`, `file_data.content`).
- Add/adjust type hints on touched functions to lock inter-module contracts.

## Validation
- Run tests with AIContextCraft procedure (local venv):
  - verify/initialize `.aicc_venv` if needed;
  - run `.aicc_venv/bin/python -m pytest tests`.
- Verify no behavioral regression:
  - identical inclusion/exclusion (including directory exclusion via `is_dir=True`);
  - unchanged `generate_tree` and `build_output` content for equal inputs.
- Report:
  - number of tests collected;
  - pass/fail status;
  - warnings if any.
