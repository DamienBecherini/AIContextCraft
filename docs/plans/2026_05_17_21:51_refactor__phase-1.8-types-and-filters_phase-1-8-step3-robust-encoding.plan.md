# Implementation plan — Encoding robustness

## Objective
Replace current permissive file reading (`errors='ignore'`) with robust reading and encoding detection to preserve accented characters and avoid silent data loss.

## Scope
- Update reading logic in [`/opt/AIContextCraft/craft/context_builder.py`](/opt/AIContextCraft/craft/context_builder.py).
- Add robust read utility in [`/opt/AIContextCraft/craft/utils.py`](/opt/AIContextCraft/craft/utils.py).
- Add dependency in [`/opt/AIContextCraft/requirements.txt`](/opt/AIContextCraft/requirements.txt).
- Add dedicated unit tests (recommended new file: [`/opt/AIContextCraft/tests/test_context_builder.py`](/opt/AIContextCraft/tests/test_context_builder.py)).

## Implementation
1. Append `charset-normalizer` to [`/opt/AIContextCraft/requirements.txt`](/opt/AIContextCraft/requirements.txt).
2. Create `read_file_with_fallback(file_path: Path, default_encoding: str = 'utf-8') -> str` in [`/opt/AIContextCraft/craft/utils.py`](/opt/AIContextCraft/craft/utils.py) with behavior:
   - attempt 1: strict read with `default_encoding`;
   - on `UnicodeDecodeError`: use `charset_normalizer.from_path(file_path).best()`;
   - if match exists: return decoded text (log detected encoding at debug/info);
   - else: final fallback with `errors='replace'` + explicit warning (validated policy).
3. Modify [`/opt/AIContextCraft/craft/context_builder.py`](/opt/AIContextCraft/craft/context_builder.py) to replace `open(..., errors='ignore')` in `_process_files()` with `read_file_with_fallback(file_path, self.encoding)`.
4. Add encoding unit tests:
   - `iso-8859-1` or `windows-1252` case with accents;
   - assert accented characters preserved after read;
   - non-detection case: verify `errors='replace'` fallback and no crash.

## Validation
1. Prepare local environment:
   - verify `.aicc_venv` exists at [`/opt/AIContextCraft`](/opt/AIContextCraft) root;
   - create if missing (`python -m venv .aicc_venv`) then install dependencies (`.aicc_venv/bin/pip install -r requirements.txt`).
2. Run tests:
   - targeted: `.aicc_venv/bin/python -m pytest tests/test_context_builder.py`;
   - regression: `.aicc_venv/bin/python -m pytest tests`.
3. Report test evidence: tests collected, pass/fail, warnings if any.
