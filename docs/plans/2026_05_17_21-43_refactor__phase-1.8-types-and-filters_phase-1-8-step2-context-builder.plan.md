# Implementation plan — Phase 1.8 Step 2 ContextBuilder

## Objective
Move the discovery engine (`os.walk`) and file processing out of [`/opt/AIContextCraft/main.py`](/opt/AIContextCraft/main.py) into a new `ContextBuilder` class while preserving current output (tree, extension summary, `files_data`, logs, CLI options).

## Code changes
- Create [`/opt/AIContextCraft/craft/context_builder.py`](/opt/AIContextCraft/craft/context_builder.py) with class `ContextBuilder`.
- In `ContextBuilder.__init__`, inject required dependencies: `project_path`, `filter_manager`, `ignore_manager`, `encoding`, `args`, `full_body_filters`.
- Implement `ContextBuilder._gather_files() -> list[Path]` reusing current directory pruning and file filtering (currently in `main.py`) with strict log preservation.
- Implement `ContextBuilder._process_files(final_file_list: list[Path]) -> list[ProcessedFile]` to:
  - read files,
  - apply `get_python_headers` if `args.headers_only`, else `strip_comments_from_code` if `args.strip_comments`,
  - keep `track(..., disable=not sys.stdout.isatty())` progress bar,
  - keep read error logs.
- Implement `ContextBuilder.build() -> tuple[str, str, list[ProcessedFile]]` to orchestrate:
  1) `_gather_files`,
  2) `generate_tree` + `format_extension_summary`,
  3) `_process_files` if `not args.tree_only` (else empty list),
  4) return `(project_tree, extension_summary, files_data)`.
- Update [`/opt/AIContextCraft/main.py`](/opt/AIContextCraft/main.py):
  - import `ContextBuilder`,
  - replace block from “Optimized search…” through `files_data` construction with:
    - `builder = ContextBuilder(...)`
    - `project_tree, extension_summary, files_data = builder.build()`
  - keep unchanged: `--git-diff` branch, `build_output(...)`, `get_file_stats`, final write/file/clipboard/report.

## Validation
- Run Python tests with project procedure via `.aicc_venv`:
  - verify/create virtual environment if needed,
  - run `pytest` (targeted or full suite per impact),
  - report: tests collected, pass/fail, warnings if any.
- Quick CLI check that `normal` and `--tree-only` modes produce coherent output structure.
